Configuração de monitores do Windows

O Player detecta os monitores conectados a este computador. Você pode vincular cada monitor físico a uma tela diferente do DisplayHub. Monitores sem link ficam livres.

Detectando monitores...

Cada monitor configurado abrirá seu próprio player em tela cheia.

Para voltar a esta configuração durante a exibição, use Ctrl + Shift + Q em qualquer tela. A configuração fica criptografada pela proteção do Windows.
