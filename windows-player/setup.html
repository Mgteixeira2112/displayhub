DisplayHub Player

Configuração inicial do player Windows

Esta primeira versão já transforma o computador em um player dedicado. Cole o link público de uma tela do DisplayHub uma única vez; depois o aplicativo abre automaticamente em tela cheia junto com o Windows.

A credencial é armazenada criptografada pela proteção do Windows. Para voltar a esta tela no modo player, use Ctrl + Shift + Q. O pareamento por código curto será conectado nesta base na próxima etapa.
